# OpenClaw RCA Engine

A tool that analyzes why Pull Requests in the [openclaw/openclaw](https://github.com/openclaw/openclaw) repository are abandoned, with full AI code attribution from day one.

---

## Requirements

- Python 3.11+
- A GitHub Personal Access Token (read access to public repositories)

---

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/BurningFalls/openclaw-rca-engine.git
cd openclaw-rca-engine
```

### 2. Create a virtual environment and install dependencies

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 3. Configure environment variables

```bash
cp .env.example .env
```

Open `.env` and set your GitHub token:

```
GITHUB_TOKEN=your_github_personal_access_token_here
```

To generate a token: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Public repository read access is sufficient.

## Architecture

```
GitHub API
    │
    ▼
┌─────────────────────┐
│   Data Collector    │  Fetches closed PRs: metadata, comments,
│   (github_client)   │  review threads, CI/CD run results
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│   Preprocessor      │  Truncates diffs, summarizes comment threads,
│                     │  extracts CI failure messages
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│   RCA Classifier    │  LLM-based classification with evidence.
│   (Claude API)      │  Returns category + reasoning + confidence
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│   Trend Aggregator  │  Groups results, computes frequency,
│                     │  outputs ranked failure trend report
└─────────────────────┘
```
